演示视频通过报名平台单独上传，采用 MP4，时长 3—5 分钟、大小不超过 300 MB。仓库保存应用、控制代码、测试、文档和系统照片。

作品简介：知手同行面向手语入门教学与复练，结合 MaixCAM2 手部视觉、Titan 实时控制与 AmazingHand 开源机械手，提供实体示范、分步反馈和课程记录。系统设置 13 项分级练习，并提供文字沟通卡与练后建议接口。实机演示展示中级四项练习及“你好”两步动作原型，开放源码、主机测试和运行说明，支持课程与模块复用。
