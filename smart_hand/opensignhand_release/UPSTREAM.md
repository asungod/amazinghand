# 上游来源与原创边界

## 组件归属表

| 组件 | 当前事实 | 许可证/归属处理 | OpenSignHand 可主张的内容 |
|---|---|---|---|
| AmazingHand 软件 | 来自 Pollen Robotics 上游 | Apache-2.0；保留上游版权和许可证 | 与 MaixCAM2、Titan、训练状态机的集成代码 |
| AmazingHand 机械设计 | 上游开源设计或购买/复刻成品 | CC BY 4.0；保留署名，不写成自研机械本体 | 本目录不主张机械结构原创 |
| MaixCAM2 | 购买开发板 | 不把板卡/厂商 SDK 写成自研 | 视觉接入、参数组织和本地训练流程 |
| Titan Mini | 购买开发板 | 不把芯片/板卡/厂商 BSP 写成自研 | RT-Thread 上的协议接入、安全状态和训练链路集成 |
| YOLO11/其他模型 | 工程使用过视觉模型配置；逐项来源尚待核验 | 未核验模型不再分发 | 只能主张已实际编写并验证的调用、状态机和数据处理 |
| NationalCSL-DP | 如实际使用，仅作外部数据来源 | 只提供官方链接、许可、清单和校验流程，不分发人物视频 | 数据读取/清单/复现流程，不能主张数据原创 |

## 原创增量

当前项目可在证据支持下说明的自研内容包括：

- MaixCAM2 侧的视觉接入、手型训练流程与阶段状态；
- MaixCAM2↔Titan 的结构化 UART 消息、序号、CRC、ACK 和超时处理；
- Titan 侧的规则优先安全校验、状态上报和故障收敛；
- 训练计数、质量评价、会话 CSV 日志和离线演练工具；
- 针对 `OPEN_PALM`、`FIST`、`V_SIGN` 三种原型课程的接口组织。

这些增量不等于“重新发明了 AmazingHand”。提交时应把上游来源放在系统架构和材料首页可见位置，并将原创代码与上游代码按文件边界列出。
