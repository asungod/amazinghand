# 数据与模型来源清单

本清单把“当前工程实际可见的能力”和“提交前必须补齐的来源”分开。没有来源、许可证、版本和哈希的模型/数据不能随包发布，也不能在材料中当作原创成果。

## 训练和验证数据发布原则

- 按说话人/操作者或场景划分训练、验证和测试，避免帧级泄漏；
- 记录采样条件、类别数、排除规则和随机种子；
- 不发布含个人身份的视频、截图或原始帧；
- 不能用合成数据 holdout 分数代替真实用户泛化结果；
- 所有图表中的数值都必须能回溯到清单中的原始文件。
