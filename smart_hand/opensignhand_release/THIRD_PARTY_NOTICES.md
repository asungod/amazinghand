# 第三方材料说明

本文件用于把上游材料与 OpenSignHand 自研增量分开。没有列出完整依赖版本或许可证的材料，不得随本目录直接再分发。

## Pollen Robotics AmazingHand

- 来源：Pollen Robotics AmazingHand 官方仓库及其发布的机械设计资料；
- 软件许可证：Apache-2.0（以对应上游文件中的 LICENSE/版权声明为准）；
- 机械设计许可证：CC BY 4.0（以对应上游机械资料的声明为准）；
- 本项目处理方式：保留上游归属和许可证，不把手本体、上游机械图或上游代码改写成 OpenSignHand 原创；任何再分发都要同时带上适用的上游许可证和署名信息；
- 官方来源：<https://github.com/pollen-robotics/AmazingHand>。

## MaixCAM2 与 Titan Mini

MaixCAM2、Titan Mini 是购买的开发板。本项目使用其可用的摄像头、串口和实时控制能力，但没有因此取得其硬件设计或厂商 SDK 的再许可，也不在本目录复制厂商 SDK、固件或闭源二进制。若提交包需要带 SDK 或模型，必须另行核对对应版本的许可证和再分发条件。

## NationalCSL-DP（仅作为数据来源记录）

当前目录不重新分发 NationalCSL-DP 人物视频、帧图像或任何包含个人信息的样本。若训练或比较确实使用该数据集，提交包只应提供：

1. 官方项目/下载链接；
2. 实际使用版本和许可证原文位置；
3. 使用的类别、划分和预处理清单；
4. 数据包或文件的校验和，以及他人按官方渠道下载后的核验步骤。

已核对的公开来源信息：

- Figshare 页面：<https://figshare.com/articles/media/NationalCSL-DP/27261843>；
- DOI：<https://doi.org/10.6084/m9.figshare.27261843>；
- Version 3，发布日期 2025-04-04；
- 页面标注许可证为 CC BY 4.0；
- 页面列出约 17.36 GB、134140 个视频、10 位手语者、前视/左视双视角。

本项目仍需在实际下载后补齐具体使用类别、划分、预处理和所用文件哈希；以上公开页面信息不代表本项目已经下载、训练或再分发该数据集。

## YOLO、手部模型与其他模型

工程曾使用 YOLO11 视觉推理配置，也包含手部姿态/训练逻辑。但当前公开资料没有为每一个模型文件提供完整的来源、版本、训练数据和再分发许可证。本目录不打包未知权重或模型二进制。发布前必须为每个模型补充来源、许可证、输入输出、模型哈希和是否允许再分发；未核验前只能提供模型获取说明，不能把其写成原创模型。

## 禁止直接打包的材料

- `smart_hand/third_party/STServo_Python.zip`：来源/许可证状态未完成核验，禁止打包；
- 未知来源或未获再分发许可的权重、人物视频、帧图像和 SDK；
- 含个人手机号、邮箱、设备密钥、局域网地址、路径或账号信息的日志、截图和配置。

## 依赖清单的最低要求

正式发布时，应为实际随包的每个外部依赖填写名称、版本、来源、许可证、是否随包、哈希和归属文件。仅仅写“使用开源库”不足以完成开源披露。
