# 当前支持的基础手型课程

## 范围声明

OpenSignHand 初版只面向少量、可重复验证的基础手型原型。下面三个标签是软件课程标识，不等同于完整中文手语、ASL/CSL 词汇，也不提供连续手语翻译：

| 标签 | 训练目标 | 当前定位 |
|---|---|---|
| `OPEN_PALM` | 张开手掌 | 基础手型原型 |
| `FIST` | 握拳 | 基础手型原型 |
| `V_SIGN` | V 形手势 | 基础手型原型 |

课程的目标是让系统能在固定相机条件下判断“是否接近当前手型、是否保持、是否完成规定次数”，并给出训练反馈。它不判断用户是否完成某个完整手语词义，也不替代手语教师。

## 一次课程的状态

```text
待机 → 目标/课程选择 → 示范 → 模仿 → 保持与计数 → 完成/取消/超时
```

训练数据可以记录会话、目标次数、完成次数、示范/模仿时间、平均单次耗时和质量字段。CSV 记录是评估原型行为的证据，不是医疗诊断记录。

## 新增手型的最低门槛

添加第四种或更多手型前，必须同时补齐：

1. 明确、可公开的标签定义和来源说明；
2. 不含个人信息的训练/验证样本或可复现实验方式；
3. 模型来源、许可证、版本和 SHA-256；
4. 在不同光照、距离和手型条件下的误识别/漏识别记录；
5. 状态机阈值、保持时间、失败恢复和安全测试；
6. 至少一条离线测试和一条人工确认的真机测试。

没有这些证据时，只能把新手型写为“计划支持”，不能在标题、视频或 PPT 中写成已完成能力。

## 与听障人士或手语学习者场景的关系

视觉手型训练可以减少对声音的依赖，但当前原型不是完整手语翻译器。若未来增加麦克风关键词，声音只能作为教师/家属的辅助操作入口，不能成为听障人士或手语学习者完成训练的必要条件；屏幕、实体按键和视觉反馈必须保留。
