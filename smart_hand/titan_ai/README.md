# TitanTrust-Tiny

TitanTrust-Tiny is an advisory TinyML classifier for the AmazingHand Titan Mini.
It does not command servos and it cannot override the deterministic RT-Thread
safety gate.

## Purpose

The model combines a short window of structured vision and link-health features
already available to Titan:

1. target confidence (%);
2. bounding-box centre motion (% of frame diagonal);
3. bounding-box scale change (%);
4. accepted-frame arrival interval (ms);
5. arrival jitter (ms);
6. forward sequence-gap delta;
7. invalid-frame delta;
8. duplicate/old-frame delta;
9. age of the latest vision candidate (ms);
10. valid-frame ratio in the window (%).

It reports one of three advisory states:

- `TRUSTED`;
- `UNCERTAIN`;
- `ANOMALOUS`.

## Safety boundary

- The model output is telemetry/advice only in the first hardware version.
- Missing, stale, invalid or non-finite input must fail closed to `ANOMALOUS`.
- UART timeout, stale vision, calibration, temperature, voltage and servo safety
  rules remain authoritative.
- The model may eventually add an extra rejection but must never turn a rule
  rejection into an allow.
- Inference runs below communication and safety threads.

## Evidence status

The first model is trained on a deterministic synthetic fault-injection corpus
that overlaps the project's protocol fault cases. Its validation accuracy is a
software-development metric, not field accuracy and not medical evidence. A
competition claim requires independent live-session capture and Titan timing,
RAM and model-hash measurements.

## Generate the portable C prototype

```powershell
python smart_hand\titan_ai\train_titan_trust.py `
  --output-dir smart_hand\titan_ai\generated
```

The generated implementation uses a small float32 MLP on Cortex-M85 first. The
public interface is intentionally independent of the runtime so the same input
and output contract can later be backed by an INT8 Ethos-U55 model generated by
Renesas RUHMI or an officially supported TFLM/Vela flow.
