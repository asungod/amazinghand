# 手势规则掌部方向修复

## 已确认缺陷

原 `finger_extension` 是 MCP 到 TIP 的弦长与指链路径比，只测二维直线度，不测是否朝掌外伸展。指链投影成朝腕部的直线时，收起的手指仍可被当成伸直。本次用户左手 V 真机坐标复算确认该机制；不将原始参与者坐标复制进源码或公开测试。

## 最小改动

`maixcam2/gesture_classifier.py` 在规则打分前增加掌部方向判断。对每指：MCP→TIP 与 WRIST→MCP 点积为负，且 TIP 到 WRIST 的平方距离小于 MCP 到 WRIST 的平方距离时，规则伸展分记 0。否则保留原直线度。判断由掌部相对坐标导出，合成测试覆盖旋转、镜像、平移与缩放；这不证明侧转/遮挡的真实泛化。

特征提取器和可选质心模型的特征向量不变，不要求旧模型假装适配新特征。原有类别门槛、300 ms 稳定条件、丢手清零及安全门控不变。规则结果追加 `finger_straightness`；采集追加 `rule_finger_extension`，原 `finger_extension` 仍是特征原值。只读分析脚本验证新可选字段，兼容旧记录。
