# M2×18 到货后四指 Bring-up 一页 Gate 卡

状态：`PAUSED_WAITING_M2X18` · 到货前不接线、不上电、不动作

这张卡只规定顺序和证据，不预填真实 ID、方向、中心、软限位、姿态或全手限流值。
每一 Gate 完成后必须由主模型审查，未审查不得进入下一 Gate。

## Gate 0：到货清点与断电

- 拍照：M2×18 数量、螺纹外观、Frame、手指件、舵机、舵盘、螺母/垫圈。
- 核对每指所需螺钉和机械件；缺件、型号不明或螺纹型别不明时停止。
- Titan、MaixCAM2、舵机外部 6V 全部断电；保存照片和清点记录。

## Gate 1：无电机械核对

- 按官方顺序核对 Frame/拉杆/link 方向和舵机安装面。
- 只做手动自由度、干涉、卡滞和螺钉啮合检查，不接舵盘、不接连杆驱动。
- 方向不能凭照片猜；不通过则回到文档审查。

## Gate 2：单指装框只读准备

- 记录每颗舵机所在逻辑角色，真实 ID 仍为空。
- 确认唯一外部舵机电源入口、万用表量程、限流依据和紧急断电位置。
- Titan/Maix UART 与舵机总线保持隔离，禁止形成第二供电路径。

## Gate 3：单指只读枚举

- 仅在主模型明确放行后接入单指所需硬件。
- 逐颗读回型号、ID、位置、温度、输入电压和扭矩状态；不得猜 ID。
- 任意无响应、异常温升、焦味、持续恒流或数据矛盾：立即断外部 6V，停止重试。

## Gate 4：单指机械中心与软限位

- 先完成电气中点参考，再安装舵盘；随后断电安装拉杆/连杆。
- 方向、中心、软限位只记录实测值；不得把 511 或离线 fixture 值直接写入生产配置。
- 任何卡滞、反向、越限或反馈不新鲜，立即停机并使本 Gate 失效。

## Gate 5：逐指扩展

- 按 F1 → F2 → F3 → F4，每次只增加一指，保留上一指证据。
- 每一指都必须完成只读枚举、机械检查和单指校准记录。
- 不得跳过单指 Gate，也不得把两舵机结果外推为四指结果。

## Gate 6：八舵机整组只读与供电审查

- 8 个角色、8 个唯一 ID、8/8 新鲜反馈必须完整。
- 供电电压、限流、峰值电流、压降、温升和停止证据必须来自现场记录；两舵机参数不得外推。
- 外部 6V 默认保持关闭，直到本 Gate 明确批准。

## Gate 7：无负载同步与抓握

- 仅在 Gate 0～6 全部通过后，才讨论空载同步、单物体抓握和三类姿态。
- 任一舵机失败时，整组 fail-closed；软件 torque-off 不能替代外部 6V 断开。
- `ACK`、`accepted`、`STATUS`、`INTENT` 和 `MOTION LOCKED` 均不能单独证明舵机执行。

## 任何阶段的立即停止条件

发热、焦味、堵转、持续 C.C、过流、通信丢失、方向不明、反馈缺项或线束异常：

1. 立即关闭外部舵机 6V；
2. 不为了补写 `torque=0` 而重新上电；
3. 保存最后反馈、面板读数和照片；
4. 标记当前 Gate 为 `BLOCKED`，回退到主模型审查。
