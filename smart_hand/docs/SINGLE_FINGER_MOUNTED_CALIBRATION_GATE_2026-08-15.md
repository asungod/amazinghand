## 3. Gate 0：断电照片审查（装框已完成，本门只做审查）

必须全部满足：

- 外部 6V 输出关闭，Type-C 与转接板均可先拔除；
- 复核两颗舵机固定在官方指定的指框位置，螺钉不干涉输出轴；
- 确认**未**安装舵盘、**未**安装连杆、**未**安装会限制输出轴的零件；
- 手动确认两颗舵机和线束没有被结构挤压；
- 拍摄指框正面、背面、两侧和转接板供电入口照片；
- 由主模型核对 ID 与安装位置、线束、唯一外部供电入口后，才能进入 Gate 1。

**官方核对判据（照片审查用，不是重装指令）：**

- 正视输出轴、指根枢轴朝上、线缆朝下时：**ID2 在左、ID1 在右**
  （官方 p21 照片标注；p23 / p27 正文 `right servo horn (ID1)` / `left servo horn (ID2)`）；
- 两颗输出轴**远离**指根外展/内收枢轴（官方 p18 原文
  `Be aware to orient them as well as the servo axis is far from the abduction / adduction pivot of the finger`）；
- 螺钉从**有 ⌀2.2 浅沉孔的那一面**拧入（该面即贴合舵机的一面；part1 上舵机孔是**距大圆枢轴孔较远**的那一对）。

ID1/ID2 左右位置必须以官方页与现场照片核对，**不能凭记忆或线色决定**。

现场记录模板：`../validation_reports/single_finger_gate0_gate1_template_2026-08-15.md`

## 5. Gate 2：断电安装手指机构与球头拉杆（**当前被 `M2x18` 阻断**）

> **顺序说明**：本门在旧版本中是"电气中点保持与安装舵盘"。
> 按官方 p19 → p20 → p22，球头拉杆必须**先**接到 link，舵盘**随后**才上输出轴，
> 故本门与原 Gate 3 内容已对调。

前置：Gate 0 与 Gate 1 均已由主模型批准；`M2x18` 已到货且数量经核对。

全程**断电**（外部 6V 关闭，确认 `torque=0`），依官方顺序：

1. **手指机构本体**（官方 p13–p16）：Proximal / Distal / Gimbal / Link + D2x10、D2x16 轴
   + `M2 L25mm` 螺纹杆插入 link；按官方 p16 装指壳，4× 热塑螺钉 2.5x6，**不要拧过紧**；
2. **球头拉杆 ×2**（官方 p10–p11）：每根 = 2× M2 球头 + **1× `M2 L18mm`** + 1× Spacer，
   用 Length tooling 定长后，将一只球头旋转 90° 使两端互相垂直；
3. **舵盘组件 ×2**（官方 p12）：Custom servo horn + `M2x10` 螺钉 + `M2` 螺母，
   把舵盘固定到球头拉杆的一端；
4. **手指机构插入指框衬套**（官方 p19）：`M2.5` 大垫圈 + `2.5x8` 热塑螺钉锁进 gimbal 孔；
   **不要拧太紧**，手动确认外展/内收活动顺畅且间隙最小；
5. **球头拉杆自由端接到 link 的 M2 螺纹杆**（官方 p20），两侧 `M2` 螺母锁紧
   （官方要求接触后再多拧至少半圈）；此时**舵盘仍悬空、未上输出轴**；
   官方 p20 原文提醒：`by ensuring servo horn is in the good way to be later assembled on servo axis`；
6. 在**不强拧舵机输出轴**的前提下手动检查机构是否有明显装反、干涉或死点。

本门**不上电、不产生舵机动作**。完成后仍保持断电，等待主模型批准进入 Gate 3。

## 6. Gate 3：电气中点参考与安装舵盘

> 本门在旧版本中是 Gate 2。只有 Gate 2（机械装配）完成并经主模型明确批准后才能执行。

1. 保持 6V 输出关闭，把限流从 1.0A 设置为 2.0A；
2. 复核机构已按 Gate 2 装好、输出轴周围无零件或人手；
3. 使用 `center_hold_scs0009_pair.py --frame-mounted-confirmed`，低速移动并保持两轴在原始值 511；
4. **`511` 只叫"电气中点参考"，绝不能写成机械中心**
   （官方 p27 示例本身把 ID1 从 511 调到 520）；
5. 保持期间按官方 p22 / p26 的相位把舵盘压上输出轴，用 **`M2x4`** 中心螺钉固定；
   官方相位判据是图示比对，正文写明只能 `as closed as you can`；
   若必须接近旋转部件，动作前先明确脚本状态和断电策略；
6. 按官方 p23 / p27 精调中点：**手指闭合时舵盘应与舵机中平面对齐**；
   Arduino 路线 1 step = 0.293°；
7. 完成后关闭 6V，再做任何机械装配调整。

本门不是生产校准，**不得把 511 写入生产 CSV 作为机械中心**。

## 7. Gate 4：实测安全范围与完整单指低幅冒烟

只有 Gate 3 完成、机构确认无阻挡并经主模型授权后：

1. 手动确认全行程无明显卡滞；记录两舵机实际动作方向和机构趋势；
2. 逐步测量真实安全最小值、参考中心值和最大值，**不能直接采用 20、511、1003**；
3. 任一数值不确定时保持校准 CSV 为空；
4. 取得实测值后才可使用：

```text
finger_smoke_scs0009.py --center1 <实测值> --center2 <实测值> --mechanism-free-confirmed
```

首次动作保持低速、小幅，并全程准备直接关闭外部 6V。
不得为了"让它动起来"提高限流、扩大幅度或绕过脚本拒绝。

**方向不得推断**：官方 `Overview.pdf` p2 只说「同向＝屈伸、反向＝内收外展」，
未给出与 SCS0009 原始寄存器方向的映射，且官方 p23/p27 自述 `rotation way is not obvious`
→ `direction_sign` 必须实测。

## 8. 全阶段立即停止条件

出现任一情况，立即关闭外部 6V，不依赖软件命令停止：

- 异常撞击声、持续嗡鸣、明显卡滞或机构无进展；
- 电源持续进入 C.C；
- 舵机、线束或转接板明显升温，或任一舵机温度达到 50 °C；
- 机构朝预期相反方向运动或靠近硬限位；
- 舵机/框架发生位移，螺钉松动；
- 串口错误、设备消失、脚本异常退出或状态不可确认；
- 焦味、烟雾或异常 LED。

停止后保持断电，保存现场照片和完整终端输出，不要立即重试。
