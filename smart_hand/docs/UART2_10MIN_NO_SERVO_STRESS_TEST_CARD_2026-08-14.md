# UART2 10分钟无舵机压力测试操作卡（2026-08-14）

- 版本：2026-08-14
- 适用对象：离线操作卡，仅供参考，不执行真机测试
- 硬件访问状态：`hardware_accessed = false`
- 本卡用途：记录一次无舵机、独立供电、三线交叉的短时压力观察，作为离线参考，不构成任何验收或操作指令

## 1. 前置条件（必须满足后才能进行任何测试）

- 舵机完全断开电源和控制线
- MaixCAM2 与 Titan Mini 各自独立 USB 供电（不得两板共用电源）
- 两板之间仅连接正确三线：GND、交叉 TX/RX
- 严禁连接任何 3V3 或 5V 电源
- 使用 Titan H1 三针 UART2 接口（不使用 40 针 U18 的供电脚）
- MaixCAM2 运行 mock 模式（无需真实视觉输入）
- Titan 启动后监听 uart2，波特率 115200
- 两板均已冷启动，串口设备正常可见

## 2. 分阶段观察时间点

每次时间点需记录：
- Maix 统计（sent / acked / timeout / consecutive_timeout / malformed / rx_errors / rtt_avg / rtt_max / pending）
- Titan 状态（link、sh_status、last VISION seq、是否异常复位）
- 是否出现异常发热 / 焦味 / 异常 LED / 串口消失

| 时间点 | 要求记录内容 | 备注 |
|---|---|---|
| 上电后 15 秒 | 初始 Maix 统计、Titan 首次收到 VISION | 确认连接正常 |
| 1 分钟 | 连续统计、Titan link 状态 | 观察是否有掉帧 |
| 3 分钟 | 持续统计、Titan 收帧统计 | 确认无异常复位 |
| 5 分钟 | 持续统计、Titan 收帧统计 | 确认无异常复位 |
| 10 分钟 | 持续统计、Titan 收帧统计 | 确认无异常复位 |

## 3. 通过条件（必须全部满足）

- timeout = 0
- malformed = 0
- rx_errors = 0
- tx_fail = 0
- ACK 持续增长（可允许最多 1 个 pending，但必须观察到后续 ACK 推进）
- Titan 持续收到 VISION 帧
- 无任何异常复位、掉电、串口设备消失
- 无异常发热、无焦味、无烟雾、无明显升温
- 舵机始终断开，无任何机械动作

## 4. 立即停止条件（发生任一即停止测试）

- 任一板出现明显发热
- 焦味、烟雾、异常 LED 闪烁
- Windows 串口设备消失
- 任一板反复重启
- timeout、malformed、rx_errors、tx_fail 持续增加
- 导线或接头发热

发生后立即断开两板 USB 供电，不允许带电重新插线或尝试恢复。

## 5. 明确限制（本卡仅用于记录参考）

- 本卡仅作为离线观察卡，不执行任何真机测试
- 不得修改 D 盘 RT-Thread Studio 工程
- 不得修改协议、CRC、Titan 安全门、校准 CSV、生产姿态
- 不得把本次短时 ACK 证据写成“长期热安全已通过”或“整机联调成功”
- 不得增加任何舵机写入或姿态配置
- 观察过程中若出现任何异常，立即停止观察并断开电源

## 6. 结束语

本操作卡仅供参考，不构成任何操作指令。执行前请确认所有前置条件已满足，并严格遵守停止条件。任何怀疑或异常必须立即停止并断开电源。
