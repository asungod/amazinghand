# 到货后的四张接线核对卡

> 每次接线先断电，用万用表和丝印确认 GND、pin1 和电压。线色只能帮助整理，不能作为
> 电气定义。以下卡片按当前官方原理图与已确认接口整理；J-Link转接板的具体方向必须
> 以实物pin1标记为准。
>
> **2026-08-14**：UART2 链路只用 Titan **独立 H1 三针**，禁止用 40 针 U18（U18 pin1
> 是电源网络，不是 GND；历史发热与此有关）。H1 三线交叉、不接 VCC 的短时双向 ACK
> 已验证；15 秒无发热 ≠ 长期互连验收。禁止两板 3V3/5V 互连；舵机保持断开。

## 卡1：J-Link → Titan 调试口

用途：下载和调试 Titan 固件。

准备：J-Link、20pin 2.54mm → 10pin 1.27mm Cortex调试转接板/排线。

断电核对：

- [ ] Titan调试口和10pin插头的 pin1 标记一致；
- [ ] 转接板不是仅改变间距却改变了针脚定义的未知型号；
- [ ] `VTref`、`GND`、`SWDIO/JTAG`、`SWCLK/JTAG` 对应连续；
- [ ] `nRESET` 是否连接按BSP/J-Link配置确认，不能拿电源脚代替；
- [ ] J-Link只检测目标参考电压，不用未知电压给Titan反向供电；
- [ ] RT-Thread Studio目标芯片使用Titan BSP自带/明确匹配RA8P1的配置。

通电后先做：只连接调试器和Titan USB，确认J-Link能识别目标；失败时断电检查pin1、
VTref和GND，不换“相近芯片”碰运气。

USB-TTL不能替代J-Link烧录普通工程。

## 卡2：USB-TTL → Titan UART1控制台

用途：观察启动日志和运行msh命令。USB-TTL必须为3.3V逻辑。

```text
Titan 40pin pin 8  / TXD1 / P707  -> USB-TTL RX
Titan 40pin pin 10 / RXD1 / P706  <- USB-TTL TX
Titan 40pin pin 6  / GND           -> USB-TTL GND
```

- [ ] TX/RX交叉；
- [ ] 只接TX、RX、GND，不接USB-TTL的VCC/5V/3.3V；
- [ ] Titan使用自己的USB供电；
- [ ] 串口参数为115200、8数据位、无校验、1停止位；
- [ ] 下载复位后看到启动日志和 `smart_hand: listening on uart2 at 115200`；
- [ ] 运行 `list_device`、`free`、`ps`、`sh_status` 并保存输出。

无日志时先检查逻辑电平、交叉接线、共地和串口号，不先改程序。

## 卡3：MaixCAM2 正面 UART2 ↔ Titan UART2

用途：传输PING、VISION和ACK结构化消息。

```text
MaixCAM2 U2T / B0 / UART2_TX -> Titan H1 pin 2 / RXD2 / P802
MaixCAM2 U2R / B1 / UART2_RX <- Titan H1 pin 3 / TXD2 / P801
MaixCAM2 GND             -> Titan H1 pin 1 / GND
```

**2026-08-14 短时闭环**：在独立 USB 供电 + 三线交叉 + 不接 VCC 的条件下，Maix sent=104 / acked=104，timeout=malformed=rx_errors=0。**仅覆盖本次短时窗口**，不能外推为长期互连或 10 分钟压力。
两板之间仍禁止连接 VCC；舵机必须保持断开。

- [ ] 两板断电后连接；
- [ ] H1 pin1方向按实物标记确认；
- [ ] 两板分别USB供电；
- [ ] 只连接TX、RX、GND，绝不连接两板5V/VBUS；
- [ ] Maix先运行 `time_api_probe.py`；
- [ ] 首次联调保持 `VISION_MODE="mock"`；
- [ ] Titan UART1控制台持续可见；
- [ ] 连续10分钟后再测试断联1.5秒和自动恢复。

## 卡4：PC/Waveshare转接板 → 单指两舵机独立电源

用途：在通信基线完成后进行SCS0009单指低风险测试。

```text
电脑 USB      -> 转接板 Type-C（只负责数据/控制，不给舵机供电）
实验电源 V+   -> 转接板绿色端子 DC+
实验电源 V-   -> 转接板绿色端子 DC-
两颗舵机      -> 两个 D/V/G 总线插座
```

- [ ] 绿色端子与DC圆孔只能二选一作为外部舵机电源入口，严禁同时接入；
- [ ] 按转接板丝印并用万用表确认极性，不得按导线颜色猜测；
- [ ] PC校准期间 Titan 与 MaixCAM2 均不接舵机转接板；
- [ ] 单颗舵机识别、只读和小步测试：6.0V、1.0A限流；
- [ ] 双舵机只读可从1.0A开始；任何双舵机移动/保持/机构测试前，先关闭输出，再把限流设为2.0A；
- [ ] 保护地端子不代替直流输出负极；
- [ ] 先只接1只舵机做只读扫描；
- [ ] 两只舵机ID唯一后才允许同总线连接；
- [ ] 原始值511只作为电气中点参考，不得写成已测机械中心；
- [ ] 舵机未装拉杆时先确认方向、参考点和小步运动；
- [ ] 安装机构后先验证软限位、低速、小范围和人工断电；
- [ ] 运动/保持/校准期间任一舵机温度达到50°C，或出现持续限流、异常声音、卡滞、失控、大量掉线，立即关闭6V输出。

现有5A实验电源可用于单指调试，但不能据此认定完整8舵机整手供电已经满足。

## 建议打印方式

将每张卡单独打印或截图放在对应设备旁。实际接线完成后拍一张能同时看到接口丝印和
线序的照片，再通电；不要只拍线束中段。
